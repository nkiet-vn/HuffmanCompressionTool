Font policy (SIL Open Font License)
===================================

The QML theme requests exactly three families: Fraunces (display),
IBM Plex Sans (interface), and JetBrains Mono (data). No font binaries
are included in this source distribution. Install these fonts system-wide,
or add their licensed .ttf/.otf files as Qt resources yourself.

Official upstream repositories and license files:
- Fraunces: https://github.com/undercasetype/Fraunces
- IBM Plex: https://github.com/IBM/plex
- JetBrains Mono: https://github.com/JetBrains/JetBrainsMono

All three are available under the SIL OFL 1.1. Preserve their OFL license
texts when distributing any bundled font binaries. All three have Latin
Extended Vietnamese support in their current releases; validate font
subset and coverage whenever changing a face or version.
